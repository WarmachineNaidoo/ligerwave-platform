Ligerwave AR Company API

WiFi CSI security platform — AR company integration endpoints.

Base URL: https://ligerwave.tech/ar

Pass your API key in the X-API-Key header.

Endpoints

GET/ar/dispatch

List all properties you have access to.

Response: {
  "homes": [
    {
      "id": "...",
      "name": "...",
      "address": "...",
      "status": "armed"
    }
  ]
}

GET/ar/dispatch/{home_id}/events?limit=50

List events for a property. Optionally filter by event_type.

Response: {
  "home_id": "...",
  "events": [...]
}

GET/ar/dispatch/{home_id}/status

Get current status: armed/disarmed, last event, 24h intrusion count.

GET/ar/dispatch/{home_id}/live

Server-Sent Events stream of live events. Connect with EventSource.

POST/ar/dispatch/{home_id}/acknowledge?event_id=...

Acknowledge an alert. Requires dispatch permission.

GET/ar/keys

List all API keys across your properties.

PUT/ar/keys/{key_id}/revoke

Revoke an API key.

Permissions

LevelAccess
read_onlyView events and status
dispatchView + acknowledge alerts
adminFull access including key management

Rate Limits

100 requests per minute per API key. Returns 429 Too Many Requests on exceeding.

Example Usage

curl -H "X-API-Key: csi_..." https://ligerwave.tech/ar/dispatch
